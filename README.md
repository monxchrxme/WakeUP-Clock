# WakeUP Clock

Личный будильник для Android 8+ и QR-станция для ноутбука. Без подписок, аккаунтов, рекламы и backend. Приложение и сайт используют тёмную палитру Gruvbox Material. [План и устройство проекта](docs/PLAN.md).

**Сайт:** [wake-up-clock.vercel.app](https://wake-up-clock.vercel.app)

**[Скачать APK 0.3.1](https://github.com/monxchrxme/WakeUP-Clock/releases/download/v0.3.1/wake-up-clock-0.3.1-debug.apk)** (около 3 MB, debug-сборка).

**[Репозиторий и релизы](https://github.com/monxchrxme/WakeUP-Clock)**. APK размещаются в GitHub Releases; в исходники сайта они не входят.

## Возможности

- Несколько будильников: время, дни недели или однократный звонок.
- Выбор нескольких будильников кнопкой «Выбрать» или долгим нажатием; выбор всех, отключение и удаление выбранных.
- Свайп справа налево удаляет только одну строку. Панель «Отменить» возвращает удалённые будильники вместе с расписанием. Выбор сохраняется при повороте экрана; нажатия на галочки не прокручивают список к началу.
- Выбор системной мелодии, громкость 20–100% (у новых будильников — 100%), встроенный запасной звук.
- Обычная либо усиленная настойчивость с восстановлением громкости. Вибрация и нарастание звука за 10/30/60 секунд настраиваются отдельно.
- Отключение кнопкой либо свежим QR с заранее связанного браузера. Закрытие сканера/экрана не останавливает сервис со звуком.
- Необязательная отсрочка на 5/10/15/20/30 минут, максимум 1–3 раза. Отдельная проверка подъёма: один повтор после отключения. По умолчанию оба варианта выключены, в QR-режиме повтор требует QR.
- Название будильника и выбор аудиофайла через системный файловый диалог. Выбранный файл копируется в закрытое хранилище приложения и проверяется декодером до сохранения, постоянный доступ к исходнику не нужен. Размер файла — до 100 МБ.
- Последняя успешно выбранная мелодия запоминается для следующих будильников, пока не выбрана другая. Уже созданные будильники и их громкость не изменяются. Мелодия зациклена; её окончание не выключает звонок.
- Редактор с колёсиками часов/минут, сгруппированными строками и кнопками «Отмена» / «Готово». Черновик сохраняется при повороте экрана и выборе мелодии.
- Восстановление расписания после перезагрузки/обновления, смены времени и часового пояса; очередь одновременных звонков.
- Сворачиваемая проверка разрешений: после настройки блок свёрнут по умолчанию. Отдельный пробный звонок останавливается кнопкой и не создаёт повторов.

## Первый запуск на телефоне

1. Скачай APK из [релиза v0.3.1](https://github.com/monxchrxme/WakeUP-Clock/releases/tag/v0.3.1) либо установи локальный `app/build/outputs/apk/debug/app-debug.apk`. Справка на сайте тоже ведёт к APK в GitHub Releases. Это тестовая сборка 0.3.1; публикации в Google Play нет.
2. Открой приложение. Разреши точные будильники и уведомления. На Android 14+ проверь разрешение полноэкранного показа. Главный экран покажет недостающие разрешения.
3. **Poco X3 Pro / Android 12 / MIUI:** в системных настройках приложения включи автозапуск и убери ограничения батареи. Проверь дополнительные разрешения показа на заблокированном экране, если они есть в прошивке. Точные названия пунктов зависят от версии MIUI.
4. Открой сайт на ноутбуке в обычном браузере → «Создать станцию». На телефоне нажми «Связать с браузером», разреши камеру, отсканируй код привязки и подтверди. Закрой окно привязки на сайте.
5. Добавь будильник. Выбери QR и усиленную настойчивость. Проверь звук через «Пробный звонок»; у него есть отдельная кнопка остановки.
6. Поставь настоящий будильник через 2–3 минуты, заблокируй телефон и проверь, что он звонит и отключается свежим кодом сайта. Повтори после перезагрузки и с закрытым приложением.

Сайт должен открываться **в том же браузере и по тому же адресу**, где была привязка. На обоих устройствах включи автоматическую дату и время. После очистки localStorage, использования нового браузера или смены домена нужна повторная привязка **до следующего QR-будильника**. У приложения нет доступа к интернету; код проверяется локально.

При обновлении устанавливай APK поверх старой версии, не удаляя приложение. Будильники, привязка и настроенные повторы сохраняются. При обновлении с v0.1.0 отсрочка и проверка подъёма остаются выключены до явного включения.

После обновления до 0.2.1 один раз выбери свою песню заново: приложение сохранит проверенную копию. Если формат не поддерживается, появится сообщение об ошибке; предыдущая мелодия останется выбранной. Если сохранённая мелодия недоступна во время звонка, экран явно покажет использование запасного сигнала.

На время первых проверок оставь привычный резервный способ пробуждения. Сборка APK и модульные проверки не подтверждают поведение MIUI на настоящем устройстве.

## Сборка Android

Нужны JDK 17 и Android SDK: platform 36, Build Tools 35.0.0. Открой корень проекта в Android Studio либо выполни:

```sh
./gradlew testDebugUnitTest assembleDebug
```

На Apple Silicon можно скачать инструменты в игнорируемую папку `.tools`:

```sh
bash scripts/bootstrap-macos.sh
bash scripts/android.sh testDebugUnitTest assembleDebug
```

Скрипт предлагает прочитать и принять лицензию Android SDK. Никакие глобальные Java/SDK настройки он не изменяет. Gradle Wrapper и дистрибутив проверяются по SHA-256. При повторной установке новой сборки используй тот же ключ подписи; debug-ключ обычно находится в `~/.android/debug.keystore`.

Установка через USB после включения отладки и подтверждения на телефоне:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Сайт локально и в Vercel

В `web/public` — обычные HTML, CSS и JavaScript. QR-библиотека включена в исходники, внешних CDN и сборки нет. Запуск из корня:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory web/public
```

Открой `http://localhost:4173`. Web Crypto требует HTTPS либо localhost. `localhost` и `127.0.0.1` — разные хранилища, как и разные домены Vercel.

Проверки сайта:

```sh
cd web
node --test tests/*.test.js
```

В Vercel используется проект **`wake-up-clock`**, подключённый к репозиторию **`monxchrxme/WakeUP-Clock`**. Настройки проекта:

- Production Branch: **`main`**;
- Root Directory: **`web`**;
- Framework Preset: **Other**;
- Build Command: **пусто** (override включён);
- Output Directory: **`public`**;
- Install Command: **пусто** (override включён, внешних зависимостей у сайта нет).

Конфигурация и заголовки уже в `web/vercel.json`. Первоначальная настройка и повторный деплой после изменения параметров выполняются в Vercel; последующие коммиты в `main` запускают деплой автоматически через GitHub-интеграцию. APK не нужно загружать на Vercel: ссылка в справке ведёт к файлу в GitHub Releases. Если изменился домен сайта, повторно свяжи браузер и телефон.

## Управление списком

Нажми «Выбрать» рядом с заголовком списка либо удержи строку будильника. Отметь нужные строки; в верхней панели доступны выбор всех, отключение и удаление. Кнопка «Назад» завершает выделение. Обычное нажатие на строку открывает редактор, переключатель справа включает или отключает будильник.

Свайп справа налево удаляет только будильник под пальцем. Короткое движение по переключателю меняет его состояние; в режиме выбора удаление свайпом выключено. После удаления снизу на 5 секунд появляется «Отменить» (на Android 10+ учитывается системная настройка времени для действий). Поворот экрана или возврат в приложение не продлевают этот срок. Отмена возвращает настройки и будущие срабатывания; при отозванном разрешении на точные звонки будильник возвращается выключенным с пояснением.

Групповое отключение и удаление относятся к расписанию. Уже начавшийся звонок или отложенная сессия продолжают работать по выбранному правилу отключения, включая QR.

## Выпуск APK

Актуальная тестовая сборка находится в [GitHub Releases → v0.3.1](https://github.com/monxchrxme/WakeUP-Clock/releases/tag/v0.3.1). Там же опубликован SHA-256 файла. Сборки APK, SDK, локальные кэши и ключи подписи исключены из Git.

Для следующего выпуска:

1. Измени `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Собери и проверь APK тем же ключом подписи. Текущая версия подписана локальным debug-ключом; новый ключ потребует переустановки приложения с потерей настроек.
3. Создай тег версии и GitHub Release, приложи APK и файл с SHA-256. При смене версии обнови ссылки в этом README и `web/public/index.html`.

Публикация APK и публикация сайта независимы. Ключ подписи в репозиторий и в Releases не загружается.

## Устройство и ограничения

Android: Kotlin, обычные Views, `AlarmManager.setAlarmClock`, foreground service `mediaPlayback`, полноэкранное уведомление, ZXing. Расписание и сессии находятся в device-protected storage, ключ привязки — в credential-protected storage; backup отключён. Приложение не использует Accessibility, Device Admin, сервер и фоновые сетевые запросы.

Сайт подписывает текущий 30-секундный интервал HMAC-SHA256. Телефон принимает код возрастом до 45 секунд, с допуском 5 секунд из будущего. Ключ не попадает в утренний QR. [Протокол и модель обходов](docs/PLAN.md).

Обычное приложение не может запретить системную принудительную остановку, удаление или выключение телефона. После force stop нужно открыть приложение снова. Режим «Не беспокоить», настройки производителя и аппаратные проблемы могут мешать звонку. Свежая трансляция экрана или извлечение ключа позволяют обойти QR; это препятствие для полусонного отключения, а не система физической аттестации присутствия.

## Что проверено

- Сборка debug APK для minSdk 26 / targetSdk 36. Подпись совпадает с предыдущими версиями: новую версию можно установить поверх старой, сохранив будильники и привязку.
- 32 модульных теста Android: расписание, часовые пояса, DST, HMAC, проверка QR, миграция старых настроек, предел отсрочек и однократная проверка подъёма.
- 16 проверок на эмуляторе Android 12: автоматическое скрытие панели отмены и новый срок после следующего удаления, выбор и отключение нескольких строк, выбор всех, удаление с отменой, направление свайпа, защита переключателя, сохранение выбора при пересоздании экрана, сохранение активного QR-звонка; также редактор, разрешения, повторные звонки, импорт песни без постоянного URI-доступа, воспроизведение копии после потери исходника, память мелодии, отбраковка неаудиофайлов и явный запасной сигнал.
- 5 тестов JavaScript: независимый HMAC-вектор, ротация кода, случайные ключи, валидация хранилища, генерация QR.
- В браузере: создание станции, привязка, возвращение к утреннему коду, сохранение станции после перезагрузки страницы и адаптивная вёрстка.
- QR с настоящего скриншота браузера декодирован тем же ядром ZXing 3.4.1, что используется сканером Android.
- Сайт опубликован в Vercel; production-адрес открыт в браузере.

Реальное срабатывание на Poco, камера телефона, Doze и восстановление после перезагрузки требуют проверки на устройстве. Полный ручной сценарий — в [плане](docs/PLAN.md).
