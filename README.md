# WakeUP Clock

Личный будильник для Android 8+ и QR-станция для ноутбука. Без подписок, аккаунтов, рекламы и backend. Приложение и сайт используют тёмную палитру Gruvbox Material. [План и устройство проекта](docs/PLAN.md).

**Сайт:** [wake-up-clock.vercel.app](https://wake-up-clock.vercel.app)

**[Скачать APK 0.6.0](https://github.com/monxchrxme/WakeUP-Clock/releases/download/v0.6.0/wake-up-clock-0.6.0-debug.apk)** (около 3 MB, debug-сборка).

**[Репозиторий и релизы](https://github.com/monxchrxme/WakeUP-Clock)**. APK размещаются в GitHub Releases; в исходники сайта они не входят.

**[Инструкция пользователя: как пользоваться](#как-пользоваться)** — музыка, случайные песни, QR, повторы, громкость и управление списком.

## Возможности

- Несколько будильников: время, дни недели или однократный звонок.
- Выбор нескольких будильников кнопкой «Выбрать» или долгим нажатием; выбор всех, отключение и удаление выбранных.
- Свайп справа налево удаляет только одну строку. Панель «Отменить» возвращает удалённые будильники вместе с расписанием. Выбор сохраняется при повороте экрана; нажатия на галочки не прокручивают список к началу.
- Выбор системной мелодии, громкость 20–100% (у новых будильников — 100%), встроенный запасной звук.
- Обычная либо усиленная настойчивость с восстановлением громкости. Вибрация и нарастание звука за 10/30/60 секунд настраиваются отдельно.
- Отключение кнопкой либо свежим QR с заранее связанного браузера. Закрытие сканера/экрана не останавливает сервис со звуком.
- Необязательная отсрочка на 5/10/15/20/30 минут, максимум 1–3 раза. Отдельная проверка подъёма: один повтор после отключения. По умолчанию оба варианта выключены, в QR-режиме повтор требует QR.
- «Раздражение»: второй звук поверх музыки через 1–60 минут с шагом в минуту; на проверке подъёма задержка на 5 минут дольше.
- Автоповтор: после выбранной длительности звонка звук останавливается и возвращается после паузы с шагом в 5 минут. Проверка подъёма создаётся после подтверждения, а не после автоматической паузы.
- Досрочная отмена ожидающей проверки подъёма после половины её интервала. В QR-режиме нужен свежий код связанного браузера; до начала проверки звук не включается.
- Название будильника и выбор аудиофайла через системный файловый диалог. Выбранный файл копируется в закрытое хранилище приложения и проверяется декодером до сохранения, постоянный доступ к исходнику не нужен. Размер файла — до 100 МБ.
- Случайная мелодия из собственного набора: пакетное добавление файлов, добавление по одному, удаление отдельных песен и очистка списка. При новом звонке песня выбирается без немедленного повтора. Набор запоминается отдельно; в новых будильниках режим выключен.
- Последняя успешно выбранная мелодия запоминается для следующих будильников, пока не выбрана другая. Уже созданные будильники и их громкость не изменяются. Мелодия зациклена; её окончание не выключает звонок.
- Редактор с колёсиками часов/минут, сгруппированными строками и кнопками «Отмена» / «Готово». Черновик сохраняется при повороте экрана и выборе мелодии.
- Восстановление расписания после перезагрузки/обновления, смены времени и часового пояса; очередь одновременных звонков.
- Сворачиваемая проверка разрешений: после настройки блок свёрнут по умолчанию. Отдельный пробный звонок останавливается кнопкой и не создаёт повторов.

## Первый запуск на телефоне

1. Скачай APK из [релиза v0.6.0](https://github.com/monxchrxme/WakeUP-Clock/releases/tag/v0.6.0) либо установи локальный `app/build/outputs/apk/debug/app-debug.apk`. Справка на сайте тоже ведёт к APK в GitHub Releases. Это тестовая сборка 0.6.0; публикации в Google Play нет.
2. Открой приложение. Разреши точные будильники и уведомления. На Android 14+ проверь разрешение полноэкранного показа. Главный экран покажет недостающие разрешения.
3. **Poco X3 Pro / Android 12 / MIUI:** в системных настройках приложения включи автозапуск и убери ограничения батареи. Проверь дополнительные разрешения показа на заблокированном экране, если они есть в прошивке. Точные названия пунктов зависят от версии MIUI.
4. Открой сайт на ноутбуке в обычном браузере → «Создать станцию». На телефоне нажми «Связать с браузером», разреши камеру, отсканируй код привязки и подтверди. Закрой окно привязки на сайте.
5. Добавь будильник и выбери способ отключения. Для QR сначала нужна привязка браузера. Проверь звук через «Проверить звук и отключение»; у пробного звонка есть отдельная кнопка остановки.
6. Поставь настоящий будильник через 2–3 минуты, заблокируй телефон и проверь, что он звонит и отключается свежим кодом сайта. Повтори после перезагрузки и с закрытым приложением.

Сайт должен открываться **в том же браузере и по тому же адресу**, где была привязка. На обоих устройствах включи автоматическую дату и время. После очистки localStorage, использования нового браузера или смены домена нужна повторная привязка **до следующего QR-будильника**. У приложения нет доступа к интернету; код проверяется локально.

При обновлении устанавливай APK поверх старой версии, не удаляя приложение. Будильники, привязка и настроенные повторы сохраняются. При обновлении с v0.1.0 отсрочка и проверка подъёма остаются выключены до явного включения.

Если обновляешься с версии до 0.2.1, один раз выбери свою песню заново: приложение сохранит проверенную копию. Если формат не поддерживается, появится сообщение об ошибке; предыдущая мелодия останется выбранной. Если сохранённая мелодия недоступна во время звонка, экран явно покажет использование запасного сигнала.

На время первых проверок оставь привычный резервный способ пробуждения. Сборка APK и модульные проверки не подтверждают поведение MIUI на настоящем устройстве.

## Как пользоваться

### Создание и изменение будильника

Нажми «＋ Добавить будильник». Колёсиками задай часы и минуты. В «Повтор» выбери дни недели либо «Будни». Без выбранных дней будильник сработает один раз: сегодня, если время ещё не прошло, иначе завтра. После однократного звонка его переключатель выключится. В «Название» можно задать свою подпись.

Выбери музыку и способ отключения, затем нажми «Готово» сверху. Нажатие на карточку уже созданного будильника открывает редактор. «Отмена» и системная кнопка «Назад» предлагают отказаться от несохранённых изменений. В редакторе есть отдельная кнопка удаления с подтверждением.

### Обычная музыка и память мелодии

Оставь «Случайная мелодия» выключенной и открой «Мелодия». Можно выбрать системный сигнал, «Аудиофайл с телефона» или встроенный сигнал. Для своего файла подойдёт, например, MP3 или WAV, размером до 100 МБ. Дождись подготовки: приложение проверит, что файл воспроизводится, и сохранит собственную копию. После этого доступ к исходному файлу не требуется. Неподдерживаемый или недоступный файл не заменит предыдущий выбор.

Последняя успешно выбранная **обычная мелодия** подставляется в новые будильники. Уже созданные будильники сохраняют свои настройки. Песня повторяется по кругу: её окончание не отключает будильник. Если сохранённую копию всё же невозможно воспроизвести, будет запасной сигнал и сообщение на экране звонка.

### Случайная песня и управление набором

1. В редакторе включи «Случайная мелодия» и нажми «Песни».
2. Нажми «Добавить песни». В системном окне файлов можно выбрать **сразу несколько файлов за один заход**: обычно нужно удержать первый файл, затем отметить остальные и подтвердить выбор. Точный вид окна зависит от телефона.
3. Для дополнения набора снова открой «Песни» → «Добавить песни». Можно добавить одну песню или ещё несколько; прежние песни остаются в списке. Повторное добавление того же аудиофайла не создаёт дубликат.
4. Крестик справа от названия удаляет только эту песню из набора. «Очистить список» убирает весь набор. Исходные файлы на телефоне не удаляются.
5. Закрой список кнопкой «Готово» и сохрани будильник верхней кнопкой «Готово» в редакторе.

В наборе может быть до 50 песен, каждая до 100 МБ. Список можно собирать постепенно, по одной песне. Для сохранения или проверки будильника с включённым случайным режимом нужны хотя бы **две разные песни**. Если очистил набор, добавь песни либо выключи этот режим перед сохранением будильника.

Песня выбирается при начале каждого звонка: обычного, пробного, после отсрочки и при проверке подъёма. Предыдущая песня этого будильника исключается из следующего выбора, пока в наборе есть другая. Во время одного звонка выбранная песня играет по кругу; после её окончания новая не выбирается. Закрытие экрана или восстановление сервиса не меняют выбор для текущего звонка. Название песни видно на экране звонка.

**Две памяти работают независимо:**

- Новый будильник всегда создаётся с выключенным случайным режимом и последней обычной мелодией.
- При включении случайного режима в новом будильнике появляется последний сохранённый набор песен. Его не нужно выбирать заново.
- Выключение режима не стирает набор и возвращает обычную мелодию. Повторное включение в том же будильнике возвращает его набор.
- Изменение набора одного будильника не переписывает другие сохранённые будильники.

Память обычной мелодии и последнего набора обновляется сразу после успешного выбора или изменения списка. «Отмена» в редакторе оставляет сам будильник без изменений, но не откатывает эту память для следующих будильников. Если при добавлении набора хотя бы один файл не проходит проверку, весь предыдущий набор остаётся выбранным.

### Громкость, настойчивость и вибрация

У новых будильников громкость 100%; ползунком её можно уменьшить до 20%. «Обычная» настойчивость позволяет менять громкость во время звонка. «Усиленная» возвращает установленный уровень, если его уменьшить. После завершения звонка приложение возвращает прежнюю громкость потока будильников.

Вибрация включается отдельно. «Нарастание звука» позволяет начать тише и выйти на выбранную громкость за 10, 30 или 60 секунд; вариант «Без нарастания» включает её сразу.

### «Раздражение»: наложение второго звука

В редакторе включи отдельный переключатель «Раздражение» и открой «После начала звонка». Выбери задержку от **1 до 60 минут с шагом в 1 минуту**. По умолчанию функция выключена, в том числе у уже созданных будильников.

Когда время истечёт, основная песня продолжит играть, а поверх неё добавится ещё один звук:

- В обычном режиме — та же песня со случайного места, со смещением относительно основной.
- В случайном режиме — другая песня из выбранного набора.

Оба звука повторяются по кругу до остановки звонка. Добавляется ровно один слой: число одновременно играющих песен не растёт каждую минуту. На экране звонка появляется сообщение о включившемся раздражении.

На **проверке подъёма** задержка на **5 минут дольше**: например, при настройке 2 минуты основной звонок получает второй звук через 2 минуты, а проверка — через 7. Это относится и к повторным циклам самой проверки. При выключенной функции дополнительные 5 минут её не включают.

После ручной отсрочки или автоматической паузы оба звука останавливаются; следующий звонок начинает отсчёт заново. При потере аудиофокуса, например во время телефонного разговора, оба звука приостанавливаются вместе. Восстановление сервиса сохраняет исходный отсчёт текущего звонка. Подготовленные, но ещё не звучащие будильники в очереди этот отсчёт не начинают.

### Автоповтор, если звонок долго не отключают

Включи «Автоповтор» в редакторе. Это отдельная функция от ручной кнопки «Отложить».

| Настройка | Что можно выбрать |
| --- | --- |
| «Длительность звонка» | От 1 до 60 минут с шагом в 1 минуту. По умолчанию 10 минут. |
| «Пауза перед повтором» | От 5 до 60 минут с шагом в 5 минут. При включении предлагается 5 минут. |

Например, с длительностью 10 минут и паузой 15 минут будильник сначала звонит 10 минут, затем замолкает на 15 минут и звонит снова. Циклы продолжаются до подтверждения подъёма по выбранному правилу. Если функцию не включать, ограничение длительности не применяется.

Каждый цикл использует исходные настройки громкости, вибрации, нарастания звука и раздражения. В случайном режиме выбирается новая песня без немедленного повтора предыдущей. Отсчёт раздражения начинается заново; у проверки подъёма по-прежнему добавляются 5 минут. Если задержка раздражения равна или больше длительности звонка, второй звук не успеет включиться в этом цикле.

**Автоматическая пауза не означает «Я встал».** Она не создаёт проверку подъёма. Проверка назначается только после успешного QR или нажатия «Я встал · отключить» в режиме кнопки. Во время паузы на главном экране есть «Я уже встал · подтвердить»: можно отменить будущий автоповтор без включения звука по тому же правилу. Если пауза началась, пока открыта камера, свежий QR всё ещё подтверждает подъём.

Если сама проверка подъёма долго не отключается, она тоже может автоматически уходить на паузу и повторяться, но новая проверка после её подтверждения не создаётся. Её уже звучавший автоповтор можно подтвердить во время паузы сразу, в отличие от досрочной отмены ещё ни разу не звучавшей проверки.

Ручная отсрочка сохраняет собственный предел 1–3 раза; число автоматических циклов этим пределом не ограничивается. Если Android не разрешает запланировать точный повтор, текущий звонок продолжится. Пробный звонок не планирует автоматические повторы.

### Пример совместной настройки

Допустим, ты выбрал раздражение через **2 минуты**, автоповтор после **10 минут звонка** с паузой **5 минут**, а проверку подъёма — через **20 минут** после подтверждения.

1. Основной звонок начинается с одной песни. Через 2 минуты добавляется второй звук.
2. Если подъём не подтверждён, через 10 минут оба звука выключаются. Через 5 минут начинается новый звонок; его раздражение снова включится через 2 минуты. Пока подтверждения нет, проверка подъёма не назначается.
3. После успешного QR или «Я встал · отключить» текущий автоповтор прекращается, а проверка назначается через 20 минут. Подтвердить подъём можно и во время тихой паузы.
4. Через 10 минут ожидания проверки появится «Отменить проверку»: её можно отменить заранее по выбранному правилу, не включая звук.
5. Если проверка всё же начнётся, её раздражение включится через **7 минут**: 2 выбранные минуты плюс 5 дополнительных. При отсутствии подтверждения проверка тоже уйдёт на автоматическую паузу после 10 минут своего звонка.

Все интервалы отсчитываются от начала соответствующего этапа, а настройки сохранённых будильников независимы друг от друга.

### Как отключать звонок и пользоваться QR

В режиме «Кнопка» нажми «Я встал · отключить». В режиме «QR с ноутбука» открой [сайт](https://wake-up-clock.vercel.app) на ноутбуке в том браузере, который был связан с телефоном. На телефоне нажми «Сканировать QR», при необходимости разблокируй его и наведи камеру на текущий утренний код. Код обновляется сам. Код привязки, чужой браузер и старый скриншот не подходят. Звук продолжается во время сканирования; закрытие сканера или экрана звонка его не отключает.

Привязка выполняется один раз через «Связать с браузером» в приложении и «Создать станцию» / «Привязать телефон» на сайте. QR-режим нельзя сохранить до привязки. Не очищай данные сайта и используй тот же домен; после очистки данных, смены браузера или адреса свяжи телефон заново заранее. При активном или отложенном звонке менять привязку нельзя. Автоматическая дата и время на обоих устройствах помогают избежать просроченных кодов. Утренний код действует недолго — до 45 секунд.

В справке сайта ссылка скачивания автоматически находит последний опубликованный APK в GitHub Releases, включая предварительные сборки. Версия проверяется при открытии справки и перед обычным нажатием на скачивание. Если проверка недоступна, ссылка ведёт к списку релизов на GitHub.

Для уже загруженного сайта интернет не нужен: страница продолжает обновлять код. Чтобы открыть сайт с нуля, нужен доступ к нему; приложение проверяет QR локально, без интернета. Данные станции хранятся в браузере, аккаунта и синхронизации между браузерами нет.

### Отсрочка и проверка подъёма

Оба варианта по умолчанию выключены; их можно включить независимо или вместе.

| Настройка | Что происходит |
| --- | --- |
| «Отложить» | На экране звонка появляется кнопка отсрочки. После подтверждения звук выключается на 5, 10, 15, 20 или 30 минут, затем звонок начинается снова. |
| «Число отсрочек» | Разрешает 1, 2 или 3 отсрочки. После достижения предела остаётся окончательное отключение по выбранному правилу. |
| «Проверка подъёма» | После окончательного отключения звонит ещё один раз через выбранные 5, 10, 15, 20 или 30 минут. |

В QR-режиме окончательное отключение каждого повтора снова требует свежего QR. Проверка подъёма не назначает новую проверку после своего отключения. Будущие отсрочки и проверки видны на главном экране. Они используют настройки того звонка, из которого появились: последующее редактирование обычного расписания их не меняет. При случайной музыке на каждом таком повторе выбирается другая песня из исходного набора.

### Как отменить проверку подъёма заранее

После отключения основного звонка под названием будильника появится время ожидающей проверки. До половины интервала там показано, с какого времени можно отменить её заранее. Кнопка «Отменить проверку» появится автоматически, даже если главный экран всё это время открыт.

Например, если проверка назначена через **20 минут** после отключения, досрочная отмена станет доступна через **10 минут**. При интервале 5 минут — через 2 минуты 30 секунд.

- Для режима «QR с ноутбука» нажми «Отменить проверку» и отсканируй свежий утренний QR связанного браузера. Звук для этого не включается.
- В режиме «Кнопка» достаточно нажать «Отменить проверку».
- Если закрыть сканер, использовать чужой или просроченный код, проверка останется запланированной.
- Если проверка уже начала звонить, досрочная отмена недоступна. Когда время истекает во время сканирования, приложение открывает обычный экран звонка: отключи его по выбранному правилу.

Отмена убирает только эту ожидающую проверку. Будильник на следующие дни и настройка «Проверка подъёма» сохраняются. Если исходный будильник был удалён, ожидающая проверка всё равно показывается отдельной карточкой и её можно отменить по тем же правилам. Для отложенной уже начавшейся проверки доступность отмены считается от половины её нового интервала отсрочки. Обычная отсрочка основного звонка этим способом не отменяется.

### Проверка перед использованием и разрешения

«Проверить звук и отключение» в редакторе запускает пробный звонок с текущими настройками, включая случайную музыку. У него всегда есть «Остановить проверку», даже в QR-режиме. Пробный звонок не создаёт отсрочки, автоповторы и проверки подъёма; раздражение в нём можно проверить. Запустить его во время другого активного или отложенного звонка нельзя.

Блок «Всё готово к звонку» / «Нужны разрешения» на главном экране сворачивается нажатием. В нём находятся переходы к недостающим разрешениям и настройкам батареи. После настройки блок свёрнут по умолчанию. На Xiaomi / POCO включи автозапуск и отключи ограничение фоновой работы; в режиме «Не беспокоить» разреши будильники. На Android 14+ нужно также разрешение полноэкранного показа. Внешний вид системных настроек зависит от телефона.

Обычный звонок продолжает работать после закрытия экрана и удаления приложения из многозадачности. Системная **принудительная остановка**, удаление приложения или выключение телефона могут помешать срабатыванию; после принудительной остановки открой приложение снова. После перезагрузки и обновления расписание восстанавливается, но ограничения прошивки всё равно нужно проверить на своём устройстве. Одновременные звонки обрабатываются по очереди.

### Управление списком

Нажми «Выбрать» рядом с заголовком списка либо удержи строку будильника. Отметь нужные строки; в верхней панели доступны выбор всех, отключение и удаление. Кнопка «Назад» завершает выделение. Обычное нажатие на строку открывает редактор, переключатель справа включает или отключает будильник.

Свайп справа налево удаляет только будильник под пальцем. Короткое движение по переключателю меняет его состояние; в режиме выбора удаление свайпом выключено. После удаления снизу на 5 секунд появляется «Отменить» (на Android 10+ учитывается системная настройка времени для действий). Поворот экрана или возврат в приложение не продлевают этот срок. Отмена возвращает настройки и будущие срабатывания; при отозванном разрешении на точные звонки будильник возвращается выключенным с пояснением.

Групповое отключение и удаление относятся к расписанию. Уже начавшийся звонок или отложенная сессия продолжают работать по выбранному правилу отключения, включая QR.

## Сборка Android

Нужны JDK 17 и Android SDK: platform 36, Build Tools 35.0.0. Открой корень проекта в Android Studio либо выполни:

```sh
./gradlew testDebugUnitTest assembleDebug
```

На Apple Silicon можно скачать инструменты в игнорируемую папку `.tools`:

```sh
bash scripts/bootstrap-macos.sh
bash scripts/android.sh testDebugUnitTest assembleDebug
```

Скрипт предлагает прочитать и принять лицензию Android SDK. Никакие глобальные Java/SDK настройки он не изменяет. Gradle Wrapper и дистрибутив проверяются по SHA-256. При повторной установке новой сборки используй тот же ключ подписи; debug-ключ обычно находится в `~/.android/debug.keystore`.

Установка через USB после включения отладки и подтверждения на телефоне:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Сайт локально и в Vercel

В `web/public` — обычные HTML, CSS и JavaScript. QR-библиотека включена в исходники, внешних CDN и сборки нет. Запуск из корня:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory web/public
```

Открой `http://localhost:4173`. Web Crypto требует HTTPS либо localhost. `localhost` и `127.0.0.1` — разные хранилища, как и разные домены Vercel.

Проверки сайта:

```sh
cd web
node --test tests/*.test.js
```

В Vercel используется проект **`wake-up-clock`**, подключённый к репозиторию **`monxchrxme/WakeUP-Clock`**. Настройки проекта:

- Production Branch: **`main`**;
- Root Directory: **`web`**;
- Framework Preset: **Other**;
- Build Command: **пусто** (override включён);
- Output Directory: **`public`**;
- Install Command: **пусто** (override включён, внешних зависимостей у сайта нет).

Конфигурация и заголовки уже в `web/vercel.json`. Первоначальная настройка и повторный деплой после изменения параметров выполняются в Vercel; последующие коммиты в `main` запускают деплой автоматически через GitHub-интеграцию. APK не нужно загружать на Vercel: ссылка в справке ведёт к файлу в GitHub Releases. Если изменился домен сайта, повторно свяжи браузер и телефон.

## Выпуск APK

Актуальная тестовая сборка находится в [GitHub Releases → v0.6.0](https://github.com/monxchrxme/WakeUP-Clock/releases/tag/v0.6.0). Там же опубликован SHA-256 файла. Сборки APK, SDK, локальные кэши и ключи подписи исключены из Git.

Для следующего выпуска:

1. Измени `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Собери и проверь APK тем же ключом подписи. Текущая версия подписана локальным debug-ключом; новый ключ потребует переустановки приложения с потерей настроек.
3. Создай тег версии и GitHub Release, приложи APK и файл с SHA-256. При смене версии обнови ссылку в этом README. На сайте версия и ссылка определяются автоматически из GitHub Releases; менять HTML и повторно деплоить сайт после выпуска APK не нужно.

Публикация APK и публикация сайта независимы. Сайт обращается к публичному GitHub Releases API без токена, выбирает последний по дате публикации релиз с полностью загруженным APK и учитывает prerelease. Проверка ограничена 5 секундами; при ошибке или лимите GitHub доступен переход к списку релизов. Ключ станции в этих запросах не используется. CSP разрешает для этой функции соединения с `https://api.github.com`.

Ключ подписи в репозиторий и в Releases не загружается.

## Устройство и ограничения

Android: Kotlin, обычные Views, `AlarmManager.setAlarmClock`, foreground service `mediaPlayback`, полноэкранное уведомление, ZXing. Расписание и сессии находятся в device-protected storage, ключ привязки — в credential-protected storage; backup отключён. Приложение не использует сервис Accessibility, Device Admin, сервер и фоновые сетевые запросы.

Сайт подписывает текущий 30-секундный интервал HMAC-SHA256. Телефон принимает код возрастом до 45 секунд, с допуском 5 секунд из будущего. Ключ не попадает в утренний QR. [Протокол и модель обходов](docs/PLAN.md).

Обычное приложение не может запретить системную принудительную остановку, удаление или выключение телефона. После force stop нужно открыть приложение снова. Режим «Не беспокоить», настройки производителя и аппаратные проблемы могут мешать звонку. Свежая трансляция экрана или извлечение ключа позволяют обойти QR; это препятствие для полусонного отключения, а не система физической аттестации присутствия.
